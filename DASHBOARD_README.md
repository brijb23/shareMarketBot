Parse JSON file

## 🚨 Troubleshooting

**Issue**: "No recommendations available for today"
- Solution: Click "Generate Now" button to run automation script

**Issue**: "Error loading file"
- Solution: Check that `nifty50_analysis/` folder exists and has JSON files

**Issue**: Streamlit not found
- Solution: Run `pip install streamlit`

**Issue**: Script times out
- Solution: Automation script takes max 5 minutes - give it time or check logs
